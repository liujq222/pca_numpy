# NumPy Handwritten PCA
> 花书配套Demo：从零实现PCA（中心化｜协方差矩阵｜特征分解）

## ✨ 项目简介
本项目**不直接调用sklearn的PCA接口**，仅依靠原生NumPy，严格按照PCA数学流程手动实现主成分分析：
数据中心化 → 计算协方差矩阵 → 特征分解 → 数据投影。
使用 `scikit-learn` 的PCA作为基准，用来验证手写实现结果的正确性。
适合《深度学习》（花书）学习、机器学习入门，理解PCA底层数学逻辑。

## 📖 PCA 流程回顾
输入样本矩阵 $\boldsymbol{X}\in \mathbb{R}^{n\times d}$
- $n$：样本数量
- $d$：特征维度

1. **数据中心化**（PCA必要步骤）
$$X_{centered}=X-\bar X$$
将每个特征减去该特征均值，把数据平移至原点。
> 💡 区分：中心化是强制步骤；标准化（除以标准差）非必需。多特征量纲差距很大时建议标准化。

2. **计算协方差矩阵**
协方差矩阵形状为 $d\times d$，描述不同特征之间的相关性。

3. **特征分解**
对协方差矩阵求特征值、特征向量。特征向量就是主成分方向；特征值代表对应方向上数据方差大小。

4. **投影**
选取前k个特征向量构成投影矩阵，将原始高维数据映射到低维空间。

> ⚠️ 常见现象：手写PCA输出和sklearn结果符号相反。
> 特征向量正负翻转不影响投影效果，属于正常情况，**不是代码错误**。
